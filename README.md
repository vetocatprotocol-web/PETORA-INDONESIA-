# **Daftar Fitur dan Modul PETORA INDONESIA**

PETORA INDONESIA dirancang sebagai platform terintegrasi untuk mengelola operasional klinik hewan dan petshop dalam satu perusahaan dengan dukungan banyak cabang.

Platform terdiri dari tiga aplikasi utama:

1. **Public Website** — informasi perusahaan dan layanan klinik.
2. **Internal Management Dashboard** — pengelolaan seluruh operasional perusahaan, klinik, dan petshop.
3. **Customer Portal** — layanan mandiri pelanggan klinik.

## **1. System & Organization Management**

| No. | Modul                     | Fitur utama                                                                |
| --- | ------------------------- | -------------------------------------------------------------------------- |
| 1   | System Administration     | Konfigurasi sistem, pengaturan global, audit log, dan administrasi sistem. |
| 2   | Organization Management   | Manajemen perusahaan, cabang, departemen, dan jabatan.                     |
| 3   | User & Access Management  | Akun pengguna, login, role, permission, sesi, dan akses cabang.            |
| 4   | Human Resource Management | Data karyawan, penempatan, dokter hewan, jadwal kerja, dan penugasan.      |
